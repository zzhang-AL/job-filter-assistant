# 岗位筛选助手 · BOSS直聘 / 前程无忧

一个 Chrome 扩展（Manifest V3）：在你浏览 **BOSS直聘** 或 **前程无忧(51job)** 时被动收录岗位，
结合你的**个人画像**用 AI 做**逐岗位匹配分析**，并支持接入**任意兼容主流协议的 AI 接口**。

> 纯前端、零构建（原生 ES module）；所有数据只存在你自己的浏览器里，除了你主动配置的 AI 接口，不上传任何第三方。

参考了 `designer-boss-helper` 插件的交互思路，但做了通用化改造：双平台通用、职业不限、AI 供应商不锁定。

### ⑦ 每日自动投递：定时搜索 → 审核清单 → 一键沟通

设置 → 自动投递里配置岗位关键词（可多个）、城市、工作年限、薪资范围、HR 活跃要求、匹配分门槛与每日上限。
每天到点后，插件在后台打开 BOSS 搜索页，让页面自己加载列表并向下滚动（插件仍然不直接请求平台接口），
随后补全 JD / HR 活跃、自动 AI 匹配，把**未沟通过**且匹配分达标的岗位汇总成「今日投递清单」。

- **已沟通去重**：沟通过的岗位永远不进清单；已沟通公司的**其他未沟通岗位**默认保留（可关）。
- **数量可控**：可分别设置每天自动收录多少个岗位用于补详情 / AI 匹配、每天最多纳入多少个投递清单；
  清单里每个岗位可点「不想要」一键关闭，也可勾选后批量关闭；关闭会同时标为「不感兴趣」，以后不再推荐（可在岗位库恢复）。关闭的也占当天清单名额，第二天重新计算。
- **审核后再执行**：侧边栏「投递」页可勾选 / 取消，点「确认投递」才逐个打开岗位页点「立即沟通」；
  默认在**后台标签页**执行，不抢焦点；侧边栏显示投递进度和「今日已投」数量。只发起沟通，不自动发送任何聊天消息，可随时停止。
- **中介 / 经纪人岗位**：点「立即沟通」若弹出「您已对中介等经纪人隐藏简历」，插件会按约定直接跳过，不计为失败，也不会点弹窗里的「继续」。
- **容错**：遇到未登录 / 安全验证立即停止；每个岗位先标记「投递中」再点击，后台被回收也不会重复点；
  失败或未投完的岗位可在侧边栏点「继续投递 N 个」直接续跑，不需要重新勾选；关闭标签页后仍可在清单里看到「已沟通 / 失败 / 已跳过」的结果。
- **限制**：自动投递依赖「自动 AI 分析」与已配置的 AI 接口；请控制每日数量并遵守平台服务条款。

## 核心功能

- **双平台通用**：BOSS直聘 与 前程无忧一套插件搞定；可「自动跟随当前站点」或锁定单平台视图。
- **被动抓取岗位**：在 MAIN world 劫持页面自身的 `fetch`/`XHR`，捕获岗位列表接口响应
  （BOSS `wapi/zpgeek/search/joblist.json`、51job `api/job/search-pc`）。**不逆向反爬令牌、不伪造签名**——
  让页面自己在真实登录态下把数据取回来，插件只读结果。接口未命中时有 DOM 兜底抓取。
- **BOSS 详情自动补全**：BOSS 列表接口不含 JD 正文和 HR 活跃时间。**插件不直接请求平台接口**：滚动收录后，
  在后台（不激活）新标签页逐个打开岗位详情页，读取页面渲染出的 JD 与「HR 最近活跃」（如「3日内活跃」，附观测时间）后立即关闭。
  同一时间只开一个标签页；遇到安全验证页暂停 30 分钟、未登录暂停 10 分钟。可在设置页关闭。
- **并发加速**：后台补详情可同时开多个标签页（稳健 1 / 标准 2 / 较快 3，最多 5），打开时刻依然错开，平均间隔按并发数摊薄；
  AI 分析可同时发多个请求（默认 3，最多 8，自动 / 批量 / 手动合计）。每轮先发 1 个试探，成功后才放开并发，Key 无效时只浪费 1 次。
  每小时额度用满时等待额度恢复后继续，不再丢弃队列。
- **模拟人工节奏**（设置 → 通用 → 后台标签页节奏，提供稳健 / 标准 / 较快预设，也可逐项自定义）：
  打开间隔、页面停留都在区间内偏态随机（多数偏短、偶尔较长）；停留时按 JD 长度多看几秒并分几次慢慢滚动；
  每处理随机若干个就休息一段；只在活跃时段内运行、电脑空闲时暂停；每小时 / 每天有上限；
  不严格按列表顺序逐个打开；沟通页同步间隔 9–15 小时随机。你主动点「AI 分析」触发的补全不休息、只用较短间隔。
  匹配 / 简历建议时若该岗位详情未就绪，会先插队补全再分析。
- **自动匹配等详情就绪**：开启「自动 AI 分析」后，BOSS 岗位只有在读到详情（JD + HR 活跃）之后才会自动匹配，
  列表刚收录时不会立即打分；51job 列表自带 JD，收录即可匹配。开了自动匹配时，即使关闭「BOSS 自动补全详情」也会补详情。
- **批量分析同样以详情为前置，流水线进行**：勾选里详情已就绪的立即分析；未就绪的 BOSS 岗位按人工节奏在后台补全
  （排在列表补全之前），**哪个详情一读完就马上 AI 匹配哪个**，不用等全部补完再统一跑。补不上详情的跳过并说明原因，
  不会拿列表摘要凑合分析。进度实时显示，可随时「停止批量分析」。
- **收录后自动进入下一步**：默认开启——收录 → 后台补全详情（JD + HR 活跃）→ 就绪即 AI 匹配；之前收录、已就绪但没分析过的岗位，
  再次出现在列表里也会自动分析。需已配置 AI 接口，消耗 token，可在设置中关闭。正在批量分析的岗位不会被重复分析。
  待分析列表每次从岗位库实时算出（详情就绪、未分析、未沟通、未被筛选剔除），每分钟和后台重启时都会接着跑，插件后台被 Chrome 回收也不丢；
  侧边栏显示「自动分析中 · 还剩 N 个」或最近的错误。模型输出无法解析的岗位连续失败 2 次后不再自动重试（卡片标「自动分析失败」）；
  Key 无效 / 余额不足暂停 10 分钟、限流暂停 2 分钟，不计入岗位失败次数。
- **匹配用 JD 与 HR 活跃**：AI 匹配以 JD 正文为技能与要求命中的主要依据；HR 长期未活跃会扣分并提示「岗位可能已停招」。
- **匹配评分规则**：模型只给技能 / 经验 / 要求命中 / 城市四个分项（附 0-100 标尺），综合分由程序按 40/25/20/15 加权计算，
  有硬门槛时封顶 40 分，档位按最终分推出——同样的分项永远得到同样的总分。硬门槛有明确容差（经验少 2 年及以上或不足 70%）；
  会用上画像里的硬性排除、不想要的特征和期望薪资；JD 只当数据处理，其中的指令一律忽略；画像空字段不发送。
- **已沟通去重**：后台标签页打开 BOSS 沟通页（`/web/geek/chat`）读取会话列表后关闭（每 9–15 小时随机一次，也可在设置页手动同步），
  加上通过本插件打过招呼的岗位，记为「已沟通」：不再收录、不参与批量/自动匹配；沟通过的公司，其他岗位默认也不再收录（可关）。
- **HR 活跃优先**：岗位库默认按「HR 活跃优先」排序（同档按匹配分）；HR 数月 / 半年未活跃的岗位在任何排序下都沉到最后，
  卡片变淡并标红「⚠ HR 近半年活跃」。匹配分按活跃档位由程序统一扣分（两周内 −3、本月 −6、数月/半年 −12），分析里注明扣分与 AI 原始分；
  自动匹配也是最活跃的先分析。筛选里可选「剔除 HR 长期未活跃的岗位」。
- **工作地址过滤**：筛选 → 工作地址排除词（如「银行」），地址含该词的岗位不进入列表、不自动匹配。BOSS 详细地址在补全详情后才有，
  此前只按区县 / 商圈判断。
- **经验要求以详情为准**：详情里的经验 / 学历要求优先于列表标签，之后列表再出现也不覆盖；JD 正文写明的年限（如「5年以上」）
  单独记录并显示，AI 判断硬门槛时以正文为准。
- **手动标记已沟通**：在 App 上聊过、插件没同步到的岗位，可在卡片 💬 / 当前岗位页 / 批量操作里手动标记为已沟通；
  设置 → 已沟通与屏蔽 里每条记录可点 × 撤销（标注来源：沟通页 / 插件打招呼 / 手动标记）。
- **一键屏蔽**：岗位卡片「⋯」/ 当前岗位页 / 批量操作均可屏蔽。屏蔽名单与岗位库分开存储，清空岗位库后依然不再收录；可在设置页解除。
- **不再展示**：屏蔽的、已沟通的岗位在侧边栏岗位库里不显示，在 BOSS 列表页上对应的岗位卡片也会被隐藏（只改本页显示，不发请求）。
  已沟通的隐藏规则跟随设置页的两个「跳过已沟通」开关。
- **个人画像**：上传简历（PDF / DOCX / TXT）→ AI 自动抽取结构化画像 → **你确认后再写入**；
  也可手动编辑。带完整度评分，随时**一键清除画像**。
- **AI 匹配分析**：基于画像对每个岗位打分（0–100 + 契合点 / 差距 / 风险 / 建议开场白），
  支持单个分析；**批量分析仅对勾选的岗位生效**，结果本地缓存（画像或模型变了才重算）。
- **当前岗位面板**：侧边栏顶部「岗位库 / 当前岗位」双模块。浏览某个岗位详情时自动识别为「当前岗位」并**实时跟随切换**，
  内含「岗位信息 / 公司画像 / 打招呼」三个子页。列表页点开详情抽屉（不改 URL）也能识别。
- **一键打招呼**：AI 一次生成三档招呼语（精简 / 标准 / 详细），可直接编辑（自动存草稿）；
  **复制** 到剪贴板，或 **新窗口打开并复制**——在**不打断你正在浏览的页面**的前提下，
  用一个不抢焦点的后台窗口打开岗位页，并已把招呼语复制好，你点「立即沟通」后 `Ctrl+V` 粘贴即可发送。
- **批量选择**：岗位库卡片可勾选，支持「全选 / 取消全选 / 清空选择」；勾选后底部工具栏切换为
  **批量分析（N）** 与 **批量导出（N）**。
- **批量导出**：把勾选岗位导出为分类齐全的 CSV（BOM + CRLF，Excel/WPS 直接打开），含平台 / 匹配 /
  岗位 / 薪资 / 公司 / AI 总评 / 招呼语 / 岗位描述 / 链接等分类列。
- **本地筛选**（不耗 token）：包含/排除关键词、风险词标注、城市、薪资、经验、学历、屏蔽公司。
- **多协议 AI 接入**：见下。
- **隐私**：发送给 AI 前默认脱敏（手机号/邮箱/联系方式/个人链接）；API Key 与全部数据仅存本机浏览器。

## 兼容的 AI 协议（不锁定单一供应商）

四大协议族，覆盖市面绝大多数厂商与本地模型：

| 协议 | 适配 |
|---|---|
| `openai-chat` | OpenAI `/chat/completions`——事实标准。DeepSeek、阿里百炼(兼容模式)、智谱GLM、Kimi、MiniMax、硅基流动、本地 Ollama/LM Studio/vLLM 等 |
| `openai-responses` | OpenAI 新版 `/responses` |
| `anthropic` | Anthropic `/v1/messages`（Claude），自动带 `anthropic-version` 头 |
| `gemini` | Google Gemini `generateContent`，key 走查询参数 |

内置预设一键创建（OpenAI / DeepSeek / 通义千问 / 智谱 / Kimi / 硅基流动 / Claude / Gemini / Ollama / 自定义）。
未列出的供应商，只要兼容上述任一协议，填自定义 `Base URL` 即可；还支持自定义请求 URL、模型列表 URL、额外请求头。

## 安装（加载未打包扩展）

1. Chrome 打开 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本项目根目录
4. 固定图标到工具栏。点击图标弹出快捷面板；面板里「打开岗位面板」进入侧边栏主界面。

首次使用：进入 **设置 → AI 接口** 添加一个供应商并填 Key/模型 → **设置 → 个人画像** 上传简历或手动填写。
之后正常浏览 BOSS/51job 的岗位列表，岗位会自动进入侧边栏，点「AI 分析」即可打分。

    autoApply.js           每日自动搜索配置 / 筛选 / 投递清单候选（纯函数）

## 说明与注意

- **权限**：`host_permissions` 含 `https://*/*`，用于让后台能向**你自己配置的任意 AI 接口**发请求
  （不同供应商域名不固定）。这会带来「读取所有网站数据」的安装提示，属功能所需；抓取仅在 BOSS/51job 生效。
- **关于「发送」**：经真机验证，两个平台都**不支持可靠的网页端自动发送**——BOSS 的聊天输入框被混淆无法定位、
  点「立即沟通」会跳转到独立聊天页；51job 网页端没有 BOSS 式的即时沟通聊天流。因此本插件的定位是
  **分析 + 招呼语生成 + 一键复制（手动粘贴发送）**，不承诺自动发送。每日自动投递也只点「立即沟通」，不发送消息。
- **自动投递的风险**：自动点击「立即沟通」属于模拟用户操作，可能触发平台风控。功能默认关闭，必须由你每天审核后确认；
  遇到登录页 / 安全验证会立即停止，且保留打开间隔。请遵守平台服务条款，控制每日数量。
- **合规**：仅供个人求职辅助，被动读取你自己浏览时页面已加载的数据，不做高频批量爬取。请遵守各平台服务条款，控制使用频率。
- **数据**：API Key、画像、岗位库全部保存在浏览器 `chrome.storage.local`，不上传任何第三方（除你主动调用的 AI 接口）。
- 抓取依赖各平台当前接口结构（已按 2026-09 真机逆向样本适配）；平台改版后可能需更新 `src/common/platforms.js` 与 `src/content/sniffer.js` 的匹配规则。
